# Coloris des lames du store vénitien intégré

Le [store vénitien intégré](/equipements/stores-integres.md) est un store à lames orientables
monté entre les parcloses de la menuiserie (la parclose est la baguette qui maintient le vitrage,
voir le [glossaire](/reference/glossaire.md)) ; son tablier est fait de lames en aluminium de
16 mm de largeur. « Optez pour l'un de nos nombreux coloris de lames aluminium tels que le blanc,
doré, gris anthracite, bleu pétrole… des coloris tendance pour habiller tous les types de
fenêtre. » [1 p. 3] Le nuancier en présente 56 sous le titre « Une palette riche et étendue »
[1 p. 4]. Sur les textures exclusives de la [TEXTURAL](/gammes/textural.md), le choix de la
couleur de lame passe par les techniciens PROFERM : « Sur les Textural exclusives, demandez
conseil aux techniciens PROFERM ils pourront vous orienter vers une couleur adaptée. » [1 p. 3]

Le store intégré est disponible dans tous les coloris de la collection en vigueur de vénitiens
aluminium 16 mm, **hors lames microperforées**, si les conditions de vitrage données sur
[Stores intégrés](/equipements/stores-integres.md) sont respectées [1 p. 11]. Aucune lame du
nuancier n'est désignée comme microperforée.

Une ligne par lame, dans l'ordre du nuancier (de gauche à droite, rangée par rangée). Le code est
imprimé sous la pastille, sans nom de couleur ; il commence par « U » ou par « D », lettre que le
document n'explique pas. La pastille est un **rendu indicatif** — « Photos non contractuelles –
Coloris et matières donnés à titre indicatif » [1 p. 4] : c'est le code qui fait foi. La pastille
de la U 0190 est imprimée blanche sur fond blanc et ne se distingue pas du papier ; le code
« U0204 » est imprimé sans espace.

# Tissus du store plissé intégré

Le [store plissé intégré](/equipements/stores-integres.md) a un tablier en tissu polyester en plis
de 20 mm de largeur. « Pour votre store plissé, une collection de tissus aux coloris très variés
est disponible, allant du plus clair au plus foncé pour s'harmoniser à tous les styles
d'intérieur. Des tissus transparents, semi opaques ou opaques pour une gestion lumineuse
optimale. » [1 p. 6] Les tissus sont rangés en quatre collections ; l'opacité et l'effet du tissu
sont donnés par collection, sur deux bandeaux placés sous ses pastilles [1 p. 7-8].

La classe NF EN 14501 range les protections solaires de 0 à 4 selon la chaleur qu'elles laissent
entrer : plus la classe est élevée, moins la chaleur entre dans la pièce (définition complète sur
[Stores intégrés](/equipements/stores-integres.md)). Elle est donnée par collection, avec des
exceptions nommées [1 p. 9] :

- « Les Macarons : classe 1 »
- « Les Tiramisu : classe 1 sauf l'Anthracite 5030 et la Réglisse 5045 de classe 0 »
- « Les Croquants : classe 2 »
- « Les Caramels : classe 1 sauf le Curacao 5035 et le Chocolat 5040 »

La Réglisse des Tiramisus porte le code 5032 ; le code 5045 est la Réglisse des Croquants
(**INC-33**) : la classe de la 5032 et celle de la 5045 restent donc doubles dans le tableau. La
classe des Caramels 5035 et 5040 n'est pas donnée (**INC-07**).

Une ligne par tissu, code et nom écrits comme la source les écrit. La pastille est un **rendu
indicatif** (« Photos non contractuelles – Coloris et matières donnés à titre indicatif ») : c'est
le code qui fait foi.
