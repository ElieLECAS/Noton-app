# Nuancier INNOSLIDE, catalogue général de janvier 2026

Le coulissant PVC à frappe [INNOSLIDE](/gammes/innoslide.md) se fait en trois teintes, une
teintée dans la masse (PVC coloré dans toute son épaisseur) et deux plaxées (film décor appliqué
sur le profilé, voir le [glossaire](/reference/glossaire.md)) [1 p. 8]. Une ligne par teinte ;
« Faces » dit quelle face de la menuiserie porte la teinte. La pastille imprimée est un **rendu
indicatif** : le code et le nom font foi à la commande.

| Code de la source | Nom | Famille | Faces | Finition | Restriction | Pastille |

| 9016 | Blanc 9016 | teinté dans la masse | 2 faces | - | - | ![Blanc 9016](/assets/coloris/innoslide/blanc-9016.png) |
| 9016 / 7016 | Blanc 9016 intérieur / Gris 7016 grainé extérieur | plaxé | blanc 9016 à l'intérieur, gris 7016 grainé à l'extérieur | grainé à l'extérieur | - | ![Blanc 9016 int / Gris 7016 grainé ext](/assets/coloris/innoslide/blanc-9016-gris-7016-graine.png) |

# Nuancier INNOSLIDE, dépliant de janvier 2024

Sous « Choix des coloris intérieur et extérieur PVC », le dépliant INNOSLIDE de janvier 2024

pastilles dessinées comme celles du catalogue [2 p. 3]. Une ligne par teinte ; la pastille est un
**rendu indicatif**, le code et le nom font foi à la commande.
