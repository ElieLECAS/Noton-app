# Renvois d'angle Roto NX

Le **renvoi d'angle** est la pièce d'angle de la ferrure : dessinée en équerre, elle transmet le
verrouillage d'un côté de l'ouvrant à l'autre (voir le [glossaire](/reference/glossaire.md)). Le
chapitre 5 « Renvois d'angle » du catalogue Roto NX PVC les range en standard (5.1), court (5.2),
têtière (5.3 : standard et seuil), seuil (5.4), compas (5.5) et solutions particulières (5.6 :
cintré, fenêtre inclinée, aération, gâche et sortie de tringle) [1 p. 265].

Chaque tableau a des pictogrammes en en-tête de colonne, définis dans la légende du catalogue
(voir [Légende des tableaux du catalogue Roto NX](/quincaillerie/roto-nx-legende-catalogue.md)) :
désignation (bulle), longueur, nombre de galets, type de goujon de verrouillage (galets E, P, V,
voir [Roto NX](/quincaillerie/roto-nx.md)), position (carré entouré de quatre flèches : haut,
bas), traitement de surface, N° de matériel, et selon le tableau information (« i »), jeu, axe de
ferrure, profondeur de feuillure, DIN gauche / droite, sortie de tringle, nombre de gâches
soudées [1 p. 10-11, 266-272]. Conventions de transcription :

- la **longueur** est imprimée en paire « a / b » (110 / 110, 110 / 10, 180 / 0, 110 / 0) ; le sens
  des deux nombres n'est pas défini, la paire est reportée telle quelle ;
- une désignation ou une longueur imprimée une seule fois pour plusieurs lignes (cellule
  fusionnée) est répétée sur chaque ligne ;
- une position imprimée « Haut / Bas » sur deux lignes d'une même cellule est reportée
  « Haut, Bas » ;
- au-dessus de chaque tableau, le catalogue dessine le ou les renvois d'angle sans relier chaque
  dessin à un N° de matériel : les dessins sont donc montrés ensemble, au-dessus de leur tableau ;
- les types d'ouverture sont nommés d'après les pictogrammes de la légende [1 p. 12].

Pour les références de renvois d'angle appelées par les nomenclatures de montage KSR, voir
[Composants communs Roto NX KSR](/quincaillerie/roto-nx-composants-communs.md).

# Verrouilleurs Roto NX

Le **verrouilleur** (VM dans les abréviations du catalogue) est une ferrure dessinée en tringle
plate, qui porte selon la référence aucun, un ou deux galets de verrouillage, une gâche soudée ou un
crochet (voir le [glossaire](/reference/glossaire.md)) [1 p. 13, 318-328]. Le chapitre 7
« Verrouilleurs » du catalogue Roto NX PVC les range
en plusieurs pièces (7.1 : standard, sécurité, seuils, recoupable, crémone), têtière (7.2), opposé
(7.3), crochet (7.4), plein cintre (7.5 : standard, élément cintré horizontal, élément cintré
vertical) et confort (7.6) [1 p. 317].

Les tableaux suivent la même légende de pictogrammes que ceux des renvois d'angle (voir
[Légende des tableaux du catalogue Roto NX](/quincaillerie/roto-nx-legende-catalogue.md)) :
**raccordable** (deux barres crantées emboîtées : la pièce s'accouple à une autre, « J » pour oui,
« N » pour non, **INC-288**), longueur, nombre de galets, type de goujon de verrouillage (galets E,
P, V, voir [Roto NX](/quincaillerie/roto-nx.md)), information (« i »), traitement de surface, N° de
matériel ; selon le tableau, jeu, zone de recoupe, position, nombre de gâches soudées, renvoi
d'angle intégré, largeur (LFF) ou hauteur (HFF) fond de feuillure d'ouvrant [1 p. 10-12, 318-328].
Conventions de transcription :

- une valeur imprimée une seule fois pour plusieurs lignes (cellule fusionnée) est répétée sur chaque ligne ;
- les paires « a / b » des verrouilleurs plein cintre (« 2 / – », « E / – », « 1 / 1 », « V / E ») sont
  reportées telles quelles : le catalogue ne dit pas à quoi correspond chaque membre de la paire ;
- chaque section dessine le verrouilleur au-dessus de son tableau sans relier le dessin à un N° de
  matériel : un dessin par section, au-dessus du tableau ;
- les types d'ouverture sont nommés d'après les pictogrammes de la légende [1 p. 12].

Les mêmes pièces portent d'autres noms dans les nomenclatures du manuel de montage KSR (« allonge »,
« allonge de semi-fixe », « allonge médian pour châssis cintré », « verrouilleur médian pour châssis
cintré ») : voir [Composants communs Roto NX KSR](/quincaillerie/roto-nx-composants-communs.md) et
[Configurations Roto NX KSR — châssis cintré et trapézoïdal](/quincaillerie/roto-nx-ksr-cintre-trapezoidal.md).
