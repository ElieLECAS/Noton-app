# L'avertissement qui gouverne toute la page

Le catalogue ouvre sa section accessoires par une mise en garde en gras : **« Attention tous nos
accessoires ne sont pas compatibles sur tous les modèles de portes d'entrée »** [1 p. 152].

Deux restrictions sont explicites dans le document, et elles suffisent à écarter beaucoup de
combinaisons :

| Restriction | Portée |
| --- | --- |
| Les bâtons de tirage n'existent que sur les **ouvrants 118**, les **ouvrants aluminium LUMINE** et les **monoblocs** | exclut tout ouvrant 97 |
| **Seule la béquille plaque étroite est envisageable sur les ouvrants de 97** | exclut la plaque large et les inox Vienne et Rome |

L'ouvrant 97 est donc le grand perdant des accessoires. Voir
[Ouvrants de porte d'entrée](/portes/ouvrants-de-porte.md).

# Cotes des bâtons de tirage

Longueurs des bâtons de tirage, en mm, relevées sur le catalogue portes d'entrée (p. 152). Ils
sont **tous en inox 316i** pour une meilleure résistance à la corrosion.

| Bâton de tirage | Longueur ou hauteur (mm) |
| --- | --- |
| Tube droit | toutes longueurs possibles, sur demande |
| Tube 04 | 500, 700, 810 ou 1 200 |
| Tube 05 | 425 |
| Tube 06 | 350 |
| Tube 08 | 600 |
| Tube 09 | 500 |
| Design carré | 500 |
| Design rond | 500 ou 700 |
| Tirant horizontal | 220 |

(schéma: raw/catalogue-portes-entree-2024-03.pdf, p. 152)

Le **tirant horizontal existe également en laiton**, seule exception à l'inox 316i.

Deux pièces complètent la famille, chacune réservée à des gammes précises :

| Pièce | Gammes |
| --- | --- |
| Pavé de tirage | LUMINE |
| Poignée de tirage | PERFORM, HYBRIDE, TEXTURAL |

# Poignées

| Poignée | Restriction |
| --- | --- |
| Plaque étroite | seule possible sur ouvrant 97 |
| Plaque large pour crémone 5 points | - |
| Inox Vienne | **uniquement verrouillage à la clé** |
| Inox Rome | **uniquement verrouillage à la clé** |

Relevé sur le catalogue portes d'entrée (p. 153).

Les inox Vienne et Rome ne se verrouillent qu'à la clé : pas de condamnation par béquille. À
signaler au client, c'est un changement d'usage quotidien.

# Heurtoirs

Six modèles, relevés sur le catalogue portes d'entrée (p. 153) :

| Heurtoir | Finition |
| --- | --- |
| Anneau inox | inox |
| Anneau laiton PVD | laiton PVD |
| Heurtoir en fer cémenté patiné | fer cémenté patiné |
| Cloche laiton PVD | laiton PVD |
| Porte laiton PVD | laiton PVD |
| Tête de lion PVD | laiton PVD |

**PVD** signifie *Physical Vapor Deposition*. Le catalogue avertit que **les couleurs laiton ou
PVD peuvent varier** — à montrer physiquement au client plutôt que sur photo.

# Boutons

Trois finitions : **inox**, **fer cémenté**, **laiton PVD** [1 p. 154].

**Avertissement explicite du catalogue : « Nos boutons de porte ne sont pas garantis contre la
corrosion. »** C'est la seule pièce de la documentation PROFERM à porter une exclusion de
garantie aussi directe. À faire signer plutôt qu'à découvrir en SAV, en particulier en bord de
mer.

# Boîtes aux lettres intégrées

Quatre coloris : **laiton / doré**, **argent / F9**, **noir**, **blanc** [1 p. 154].

La **faisabilité est sur demande** : ce n'est pas une option catalogue, elle se valide au cas par
cas.
